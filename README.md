# El crimen de mañana

Juego independiente de investigación narrativa para adultos. Cada expediente combina un cuento breve, lugares para investigar, personajes, pruebas y una conclusión. No todos los casos terminan con una acusación ni todos contienen un responsable penal.

## Modos

- **Carrera de investigación:** prestigio, sueldo, presupuesto, informantes, delegación, ascensos y premios variables.
- **Archivo de expedientes:** todos los casos disponibles para jugar o rejugar sin consecuencias sobre la carrera.

## Expedientes incluidos

1. El crimen de mañana
2. El retrato que cambió de lugar
3. La última llamada de Ardan
4. El testigo imposible
5. El atardecer de Verónica
6. El contrato
7. Mala idea
8. Única solución
9. El mensaje

Los casos 5, 6, 7, 8 y 9 permiten leer el cuento original después de resolverlos. Los créditos de autor aparecen dentro de cada expediente.

## Cómo ejecutarlo

Descomprimir toda la carpeta y abrir `index.html` en un navegador moderno. El juego no usa dependencias, APIs ni conexión a internet. Los archivos `index.html`, `styles.css`, `cases.js` y `app.js` deben permanecer juntos.

## Controles

Todo se maneja con mouse o pantalla táctil. Los botones **A−** y **A+** modifican el tamaño de la interfaz.
